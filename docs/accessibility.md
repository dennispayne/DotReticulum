# Accessibility

DotReticulum is an experimental command-line application. Accessibility depends
in part on your operating system, terminal and assistive technology.

We aim to keep commands usable from the keyboard, provide readable help and
error messages, and avoid conveying essential information through color alone.
Interactive terminal features may have additional limitations.

We have not completed a formal accessibility audit or verified screen-reader
compatibility, and do not claim compliance with an accessibility standard.

Please report accessibility barriers through a GitHub issue. Include the command,
expected and actual behavior, operating system, terminal and assistive technology
where relevant. Do not include private keys, credentials or private traffic.
Reports and fixes receive best-effort attention; there is no response-time SLA.
