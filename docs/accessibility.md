# Accessibility

DotReticulum is an experimental command-line application. How accessible it is depends partly on your operating system, terminal and assistive technology.

## Goals

We aim to:

- Keep commands usable from the keyboard.
- Provide readable help and error messages.
- Avoid conveying essential information through color alone.

Interactive terminal features may have additional limitations.

## Current status

We have not completed a formal accessibility audit or verified screen-reader compatibility, and we do not claim compliance with any accessibility standard.

## Reporting barriers

Please report accessibility barriers through a GitHub issue. Where relevant, include:

- The command you ran.
- The expected and actual behavior.
- Your operating system, terminal and assistive technology.

Do not include private keys, credentials or private traffic.

Reports and fixes receive best-effort attention. There is no response-time SLA.
